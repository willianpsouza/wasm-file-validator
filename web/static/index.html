WASM File Validator

Client-side Rust/WASM inspects the file, signs the verdict, and seals it to the backend. The Go backend decrypts, verifies the signature, and echoes the trusted verdict.

Demo only. The Ed25519 signing key is embedded in the published .wasm and is therefore extractable — the signature here demonstrates the mechanism, not real client authenticity. See the README.
